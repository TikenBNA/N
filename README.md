# Nude Gallery — PWA

Мобильная веб-галерея с подтверждением возраста 18+.

- Художественная ню: поиск изображений Wikimedia Commons с отображаемой лицензией и ссылкой на исходную страницу.
- Личная коллекция: локальное добавление выбранных изображений в текущую вкладку.
- Избранное и сортировка по названию.
- Адаптивный интерфейс, manifest и Service Worker.

## Публикация
Репозиторий можно опубликовать через GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Ограничения и безопасность
Категоризация основана на поисковых метаданных, а не анализе пикселей. Наличие лицензии не подтверждает возраст модели, согласие на съёмку/публикацию или любые дополнительные права. Храните только изображения совершеннолетних людей, на хранение которых есть явное согласие. Локальные файлы существуют только в памяти вкладки и исчезают после её закрытия. Поиск требует интернет-соединения; проект не загружает частные изображения на сервер.
