# Nude Gallery — PWA

Мобильная веб-галерея с двумя разделами:
- **Художественная ню:** поиск в Wikimedia Commons, отображение результатов только при наличии распознаваемых метаданных открытой лицензии.
- **Эротика — личная коллекция:** локальное добавление изображений, без загрузки на сервер и без автоматического поиска эротики в неизвестных источниках.

## Запуск
Нужен статический HTTPS-хостинг (например, GitHub Pages, Netlify или собственный сервер). Service Worker не работает при открытии `index.html` как `file://`.

1. Распакуйте архив.
2. Загрузите содержимое папки на HTTPS-хостинг.
3. Откройте адрес на телефоне.
4. В меню браузера выберите «Добавить на главный экран» / «Установить приложение».

Для локального теста можно запустить любой статический сервер, например:
`python -m http.server 8000`
и открыть `http://localhost:8000`.

## Возможности
- Адаптивная мобильная сетка.
- Поиск и постраничная загрузка Wikimedia Commons.
- Фильтрация по наличию лицензии в метаданных.
- Сортировка по названию.
- Избранное в localStorage.
- Просмотр оригинала, страницы файла, автора и лицензии.
- Локальное добавление личных изображений; файлы не отправляются на сервер.
- PWA manifest и Service Worker для оболочки приложения.

## Важные ограничения
- Wikimedia Commons API — внешний источник; поиск требует интернет-соединения.
- Проверка лицензии по метаданным не является юридической экспертизой.
- Лицензия не подтверждает возраст модели, согласие на съёмку/публикацию или право на использование изображения в любом контексте.
- Автокатегоризация основана на тексте метаданных/названия, а не на распознавании содержания пикселей. Это намеренно снижает риск ошибочной классификации людей.
- Раздел личной эротической коллекции принимает только изображения, которые пользователь вправе хранить. Файлы доступны только в текущей вкладке; при перезагрузке их нужно добавить снова.
- Это клиентский прототип без собственного сервера, аккаунтов, синхронизации и фонового обхода сайтов.

## Безопасность
Используйте только материалы, для которых подтверждены совершеннолетие изображённых лиц, согласие и права на хранение/использование. Не загружайте интимные изображения третьих лиц без их явного согласия.
